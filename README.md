# 🛒 E-commerce Database

Projeto de modelagem de banco de dados relacional para um sistema de e-commerce, desenvolvido durante o curso da **DIO**.

O modelo foi criado utilizando **MySQL Workbench**, aplicando conceitos de modelagem de dados, entidades, relacionamentos, chaves primárias e chaves estrangeiras.


## 📌 Sobre o projeto

O banco de dados foi estruturado para gerenciar:

- Clientes Pessoa Física (PF) e Pessoa Jurídica (PJ);
- Produtos e categorias;
- Pedidos;
- Itens dos pedidos;
- Formas de pagamento;
- Pagamentos;
- Entregas com status e código de rastreio.


## 📚 Conceitos aplicados

- Modelagem Entidade-Relacionamento (DER);
- Normalização de banco de dados;
- Chaves primárias e estrangeiras;
- Relacionamentos 1:1 e 1:N;
- Organização de banco de dados relacional.
